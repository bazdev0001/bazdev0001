# Hi, I'm Barry Au-Yeung 👋

**Senior DevOps Engineer · Build & Release · Open Source**

---

Over the past 12 years I've built the infrastructure that lets engineering teams ship fast and sleep well. I've lived through enough 2am incidents, misconfigured clusters, and manual rollback nightmares to have opinions about how this stuff should work.

My focus is on the unglamorous work that actually matters: robust CI/CD pipelines, reproducible infrastructure, observability that tells you *why* something broke, and deployment patterns that make rollbacks boring rather than heroic.

- **Observability** — Prometheus, Grafana, OpenTelemetry, distributed tracing
- **DevSecOps** — container scanning, secrets rotation, RBAC
- **Developer platforms** — internal tooling that makes the rest of the team faster
